# Enlaces de la Unidad 2: Introducción a las aplicaciones web
### Práctica 1: Presentación
Esta práctica consistía en preparar una exposición entre 2 a 3 personas y presentarla el vienes 10 de octubre. En esta presentación tratamos los siguientes temas entre los que podíamos elegir:  Instalación básica del servidor web Apache y en Ubuntu Server y los clientes y servidores FTP.

### Practica 2: Iniciación a la virtualización
Esta práctica consistía en crear una máquina virtual con Ubuntu 24.04 LTS, instalarle las GuessAdditions y Docker. Con Docker, instale y ejecute los contenedores Nginx y Tomcat. Finalmente, describí los requerimientos mínimos para implantar una aplicación web (hardware, software, infraestructura, seguridad...)
