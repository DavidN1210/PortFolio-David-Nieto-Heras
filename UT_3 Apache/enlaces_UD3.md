# Enlaces de la Unidad 3: Apache
### Práctica 1: Instalación de Apache en Ubuntu
La práctica consiste en instalar y configurar el servidor web Apache en Ubuntu para desplegar un sitio web personalizado. Esto incluye la creación de un Virtual Host y la documentación de la configuración, así como la resolución de un problema de resolución de dominio local. El objetivo es adquirir experiencia en la administración, pruebas y seguridad básica de un servidor web.

**Enlace:** [Instalación Apache](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UT_3%20Apache/EJ_UD3/Instalacion_De_Apache_En_Ubuntu/Instalacion_De_Apache_En_Ubuntu.md)

### Practica 2: Apache-HTTPS
Esta práctica consiste en investigar y llevar a cabo la implementación del protocolo HTTPS en un servidor web Apache2 ejecutándose sobre Ubuntu, garantizando la correcta configuración de certificados SSL/TLS y la verificación funcional del acceso seguro al sitio.

**Enlace:** [Apache-HTTPS](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UT_3%20Apache/EJ_UD3/Apache_HTTPS/apache_https.md)
