# Enlaces de la Unidad 4: Tomcat
### Práctica 1: Investigación y descripción
La práctica consiste en buscar información sobre los diferentes elementos de tomcat (Catalina, Coyote...) y hacer un resumen explicando para qué sirve cada componente y dónde se ubica en el sistema.

**Enlace:** [Investigación Tomcat](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UD4_Tomcat/EJ_UD4/Tomcat_Investigacion.md)

### Práctica 2: Identificación de archivos de configuración
La práctica consiste en, tras instalar Tomcat, localizar 4 archivos claves(conf/server.xml,conf/web.xml,conf/tomcat-users.xml y conf/context.xml) en la instalación de Tomcat, explicar cada una de sus funciones y los elementos que se pueden configurar con ellos. Por último, teníamos que hace un mapa visual de las dependencias que existen entre los rchivos.

**Enlace:** [Identificación Tomcat](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UD4_Tomcat/EJ_UD4/Tomcat_IdentificaciónDeArchivos.md)

### Práctica 3: Despligue simple de una aplicación web
La práctica consiste en descargar o crear un archivo WAR y desplegarlo en la carpeta de Tomcat `/webapps`. Gracias al despligue automático, podremos acceder a nuestra aplicación desplegada a través del navegador.

**Enlace:** [Despliegue Tomcat](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UD4_Tomcat/EJ_UD4/Tomcat_Despligue_AplicacionWeb.md)

### Práctica 4: Integración Tomcat + Servidor web
Esta práctica consiste en integrar Tomcat con un servidor web Apache para que las peticiones de los usuarios pasen primero por el servidor web y este las redirija a Tomcat.

**Enlace:** [Integración Tomcat](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UD4_Tomcat/EJ_UD4/Tomcat_Integracion_Y_ServidorWeb.md)

### Práctica 5: Configuración de seguridad en Tomcat
Está práctica consiste en configurar la seguridad de Tomcat y comprobar que el acceso autenticado funciona correctamente.

**Enlace:** [Seguridad Tomcat](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UD4_Tomcat/EJ_UD4/Tomcat_Configuracion_Seguridad.md)

### Práctica 6: Herramientas de administración — Manager y Host Manager
Esta práctica consiste en acceder a las interfaces de Manager y Host Manager y investigar sus funciones principales.

**Enlace:** [Herramientas Tomcat](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UD4_Tomcat/EJ_UD4/Tomcat_Herramientas_Administracion.md)

### Práctica 7: Pruebas de funcionamiento y rendimiento
Esta práctica trata de probar el rendimiento de tu servidor Tomcat, medir cómo responde bajo carga y aprender a ajustar su configuración para mejorar su comportamiento.

**Enlace:** [Pruebas Tomcat](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UD4_Tomcat/EJ_UD4/Tomcat_Pruebas_Funcionamiento.md)

### Práctica 8: Tomcat en Contenedores (Docker)
Esta práctica va de usar Tomcat dentro de un contenedor Docker, desplegar una aplicación dentro de él y entender qué cambia respecto a usar Tomcat instalado directamente en el sistema operativo.

**Enlace:** [Contenedores Tomcat](https://github.com/DavidN1210/PortFolio-David-Nieto-Heras/blob/main/UD4_Tomcat/EJ_UD4/TomCat_Contenedores.md)

### Práctica 9: Documentación final
Está práctica consiste en elaborar una documentación final de las prácticas anteriores.
